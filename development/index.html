Development

Updates and Notes

Follow the ongoing development of our first marine safety prototype, including hardware testing, software progress, calibration work, and field evaluations.

July 10, 2026

Initial UWB Hardware Configuration

The first development session focused on establishing serial communication with the ultra-wideband boards, confirming AT-command access, and configuring four devices as vessel reference units and one as a crew tag.

July 23, 2026

Controlled Distance Calibration Completed

Repeated measurements were collected across multiple known distances for each prototype device. The results are being used to calculate board-specific corrections and improve consistency before live vessel testing.

Current Development Phase

Preparing for Initial Vessel Testing

Development is moving toward a first field test focused on collecting live distances from multiple vessel-mounted reference devices and displaying those measurements through the onboard Raspberry Pi system.

Research Notes

Current research is focused on radio behavior around vessel structures, positioning geometry, below-deck coverage, independent wireless verification, false-alert reduction, and practical crew-device design.

Testing Updates

Testing currently progresses from controlled bench measurements to live multi-device monitoring, position estimation, boundary evaluation, and vessel-based trials. Each stage is documented so that hardware behavior and software changes can be compared over time.

Developing practical marine safety, crew-location, and search-and-rescue technologies for commercial and recreational vessels.
